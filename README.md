## 🚀 Key Features

### ⚔️ Two Dynamic Game Modes
- **Classic Mode:** The timeless 3x3 layout we all know and love. Match 3 symbols in a row to win, with options for 1, 3, or 5 rounds!
- **Modern Mode (3-Piece Limit):** A fast-paced strategic twist! Each player can only have **3 active marks** on the board at a time. Placing a 4th mark automatically fades out and removes your oldest one, keeping the game endless, tense, and highly tactical.

---

### 🤖 Intelligent Multi-Level AI
Play offline anytime against a smart computer opponent tuned with three distinct levels:
- 🟢 **Easy:** Relaxed & casual moves.
- 🟡 **Medium:** Blocks your winning lines and spots obvious victories.
- 🔴 **Hard:** Plays with strategic priorities (center control, corner trapping, and instant counter-attacks).

---

### 📡 Real-Time LAN Multiplayer (Hotspot / Wi-Fi)
No internet server? No problem! 
- Connect two phones instantly over the same local Wi-Fi or mobile Hotspot using custom asynchronous **TCP Sockets**.
- One phone hosts the room, the other joins via IP address — seamless local network multiplayer!

---

### 🎵 Smooth Audio & Mobile Experience
- **Dynamic Jukebox:** Built-in background music switcher with playlist tracks, looping toggle, and independent volume controls for music & sound effects.
- **Smart Back Button Handling:** Complete mobile navigation flow — handles hardware back buttons on Android to gracefully manage Pause menus, Settings, and Quit popups.

---

## 🛠️ Built With

- **Engine:** Unity 2D
- **Language:** C#
- **UI:** Unity TextMeshPro & Canvas Systems
- **Networking:** System.Net.Sockets (Custom P2P Architecture)
